# Python aplicado al aprendizaje

Esta carpeta se utilizará para desarrollar pequeñas herramientas que apoyen el estudio del mandarín.

## Próximas herramientas

- Quiz de vocabulario.
- Generador de tarjetas.
- Registro de palabras aprendidas.
- Práctica de tonos y Pinyin mediante datos.
- Estadísticas de progreso.

La programación se incorporará gradualmente a medida que se aprendan los conceptos necesarios.
