# Gramática básica

## Orden básico

Una estructura frecuente del mandarín es:

**Sujeto + Verbo + Objeto**

Ejemplo:

> 我学习中文。  
> Wǒ xuéxí Zhōngwén.  
> Yo estudio chino.

## Principios de estudio

- Practicar estructuras completas.
- Observar el contexto.
- Comparar patrones similares.
- Crear ejemplos propios.
