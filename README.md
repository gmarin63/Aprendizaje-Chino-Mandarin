# 🇨🇳 Aprendizaje de Chino Mandarín

Proyecto personal para aprender **chino mandarín (普通话 / Pǔtōnghuà)** de forma progresiva, organizada y práctica.

El repositorio combina estudio de idiomas con herramientas de programación y datos para construir un sistema de aprendizaje que pueda crecer junto con mi progreso.

## 🎯 Objetivos

- Aprender vocabulario y estructuras gramaticales del mandarín.
- Dominar **Pinyin** y los cuatro tonos.
- Aprender a reconocer y escribir **Hanzi (汉字)**.
- Preparar progresivamente los niveles **HSK**.
- Practicar lectura, escritura, traducción y comprensión.
- Registrar el progreso y las palabras aprendidas.
- Crear herramientas sencillas con **Python** para practicar.
- Utilizar Git y GitHub para documentar el proceso de aprendizaje.

## 📈 Seguimiento
